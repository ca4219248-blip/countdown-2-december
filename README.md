# Countdowns

Single-file, dependency-free countdown pages. No build step, no libraries.

| Date | Page |
| --- | --- |
| 2 December 2026 | https://ca4219248-blip.github.io/countdown-2-december/ |
| 10 October 2026 (already passed, counts up) | https://ca4219248-blip.github.io/countdown-2-december/october-10-2026/ |
| 1 January 2027 | https://ca4219248-blip.github.io/countdown-2-december/january-1-2027/ |
| 2 October 2027 | https://ca4219248-blip.github.io/countdown-2-december/october-2-2027/ |

All times are 12:00 AM IST (UTC+05:30).

## What each page does

- Live days / hours / minutes / seconds, updated every second
- A progress bar showing how much of the wait is over (measured from 2 November 2026)
- Total seconds remaining, in the Indian numbering system
- Switches to an "It's here" state once the target moment passes
- Dates already in the past count *up* instead, showing how long ago they were
- Responsive, dark themed, respects `prefers-reduced-motion`

## Adding another date

Pages are generated by `build.py`: add an entry to the `PAGES` list, run
`python3 build.py`, then upload the new `site/<slug>/index.html` to the repo.

## Hosting

GitHub Pages, `main` branch, root folder. A push rebuilds the site in about a minute.
